# Manrope

Variable WOFF2 files (weights 200–800), served locally for all text in the existing
dashboard, including numbers, forms, logs and Chart.js labels. Icons retain their
symbol font.

Source: Google Fonts, Manrope v20, downloaded 2026-10-01.
- Latin: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2
- Latin extended: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggmxSuXd.woff2
- License: https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt

SIL Open Font License 1.1 is included in `OFL.txt`. Both files are precached for
offline use. No Google Fonts request is made by the dashboard.
